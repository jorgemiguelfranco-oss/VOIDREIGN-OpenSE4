# VOIDREIGN

**A native, standalone 4X space strategy game for Windows and Linux.**

VOIDREIGN is built on the native C++ engine foundation of [OpenSE4](https://github.com/lowlevelmetal/OpenSE4). It uses its own generated ruleset, factions, names, technologies, ships and economy. A copy of Space Empires IV is **not required** to play.

## The game

- Build an interstellar empire across a procedurally generated galaxy.
- Explore warp networks, secure strategic chokepoints and expand through colonisation.
- Design ships and bases, build fleets, move through systems, and fight tactical and strategic battles.
- Research technologies to unlock advanced hulls, engines, colony cores, weapons, defences, sensors, shipyards, terraforming and storage infrastructure.
- Manage construction, trade, diplomacy, intelligence and computer-controlled rivals.
- Choose among eight governments with different production, research, trade and fleet-maintenance effects.
- Manage resource stockpiles: empires begin with 25,000 storage for each resource, but no free warehouse. Mineral and Organic Warehouses and Radioactive Vaults each add 30,000 capacity for their resource; a Central Warehouse adds 75,000 to all three. Stockpiles above capacity are discarded at the end of the turn.
- Start with 12 original playable factions and three independent powers, with configurable empire and galaxy setup.

VOIDREIGN keeps the engine's native fleet, design, combat, save-game and turn-processing systems. Campaign mode is not part of the game.

## Build from source

Requirements: C++23 compiler (GCC 14+, Clang 18+, MSVC 17.10+ or Apple Clang 21), CMake 3.25+, Ninja, Python 3 and glslc.

    cmake --preset debug
    cmake --build --preset debug
    ctest --preset debug
    ./build/debug/VOIDREIGN --quick-start=Aurel

The original VOIDREIGN ruleset and first-party artwork are generated from `tools/generate_voidreign_data.py` and `tools/generate_voidreign_art.py` as part of the build and copied beside the game executable. The bundled content includes original random events and a functioning intelligence/espionage catalogue, backed by OpenSE4's existing effect handlers. Each playable species and neutral power has its own native AI research doctrine, with priorities changing between exploration, infrastructure, attack, captured-system security, defence and late-game isolation. GitHub Actions is configured to compile the native client, run the test suite, validate the generated rules and art, and launch a headless game.

`--classic-dir` remains an optional compatibility override for loading an external data set; it is not needed for a normal VOIDREIGN game.

## Development status

VOIDREIGN is under active development. The native engine foundation, standalone ruleset and a build-time first-party artwork generator are in the repository. The generator now covers faction and neutral portraits, faction-specific ship miniatures/portraits, planet art, module icons, system backgrounds and the core UI sprite sheets. Higher-polish art, full integration/runtime validation and Windows/Linux release testing remain outstanding. Do not treat a draft branch or a queued CI check as a released, tested game.
