# VOIDREIGN native art conversion

These native PNGs are converted from the owner's original VOIDREIGN art library
on the art/crisis-wonders branch of jorgemiguelfranco-oss/voidreign.

Original source files, credits, and provenance are preserved in that library.
Conversion uses Pillow/Lanczos, retains alpha on ship/planet assets and makes
native-resolution PNG files for the OpenSE4 renderer. The race portrait set
uses the five existing original portrait masters, with subtle faction palette
variants where the art library has no exact species portrait yet. This is not
misrepresented as six unique original species paintings.

The source branch credits disclose AI-generated images and identify their dates
and source prompts/processors. These assets are for the native VOIDREIGN project.
