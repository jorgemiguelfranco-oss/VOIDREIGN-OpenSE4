# VOIDREIGN original game art provenance

All art listed below is bundled as native PNG/WAV/OGG game data. No external image,
audio or generation service is required at runtime. The artwork is original to VOIDREIGN
or was generated specifically for the VOIDREIGN project.

## Components and facilities

- **49 component portraits**: one 128x128 illustrated portrait for every named component
  in Data/Components.txt, with unique sequential Pic Num values.
- **29 facility portraits**: one 128x128 illustrated portrait for every named facility
  in Data/Facility.txt, with unique sequential Pic Num values.
- The compact Components.png and Facility.png sprite atlases are independently drawn
  transparent 36x36 glyphs from the same semantic design system as the portraits. The
  engine uses the atlases in lists and the 128x128 art in detail panels.
- Art is procedurally drawn by tools/art/generate_component_facility_art.py: custom
  silhouettes, bevels, lighting, category palettes and tier marks. The generator is
  deterministic and retains source names, data IDs and SHA-256 hashes in
  art-library/voidreign-art-native-components/GENERATION-MANIFEST.json.

## Faction leaders and ship classes

The six leader portraits are distinct AI-generated AlbedoBase XL (SDXL) images from the
free AI Horde volunteer worker pool. Original 512x512 WebP sources, prompts, seeds,
worker IDs, request IDs and hashes are preserved in
art-library/voidreign-art-faction-portraits/. The Veyran native portrait is cropped
to exclude a pseudo-signature artefact.

Each of the six factions has its own treatment of all twelve hull classes:
Pathfinder, Hauler, Frigate, Destroyer, Cruiser, Battleship, Colonizer, Station,
Corvette, Science Vessel, Dreadnought and Mobile Shipyard. This is 72 faction-specific
ship portraits and 72 miniatures. The silhouettes, armor plating, propulsion and faction
motifs are generated by tools/art/generate_ship_art.py. Model and worker names are not
applicable; this is deterministic procedural artwork. Details and hashes are in
art-library/voidreign-art-faction-ships/GENERATION-MANIFEST.json.

## Planetary and stellar objects

Sixteen original 128x128 object illustrations cover terrestrial, icy, gas-giant,
super-terrestrial, ocean, desert, volcanic, ringed and crystal worlds, alongside star,
asteroid-field, ion-storm and warp-point symbols. A matching 288x72 transparent atlas
provides sixteen compact 36px object icons. Surfaces use multi-scale procedural
topography, directional lighting, atmosphere and category-specific details. The
generator and per-file hashes are in tools/art/generate_planet_art.py and
art-library/voidreign-art-planets/GENERATION-MANIFEST.json.

## Star systems and tactical combat

The six native system biomes are **Starfield/Core, Nebula, Pulsar, Black Hole, Magnetar
and Warp Hub**. Every biome has one base system thumbnail and four deterministic scene
variants, each with a native 660x660 background for the 1024x768 layout and a 490x490
background for the 800x600 layout. This provides 24 individual system scenes and 48
resolution-specific variant backgrounds. Each biome also has nine coherent 72x72
tactical texture tiles (54 tactical tiles total).

The backgrounds and tiles use deterministic procedural star fields, palette-matched gas
clouds, plasma filaments, accretion rings, pulsar beams, magnetar fields and warp geometry.
The galaxy ruleset (SystemTypes.txt and QuadrantTypes.txt) assigns different frequencies
and named backgrounds to each system type. A system's stable SystemId selects its scene
variation; the System Map, Stellar view, System Report and tactical combat use the same
variation (combat uses a coherent crop of the full scene). Legacy mods still fall back to
their own tile mosaics or unvaried bitmap backgrounds.

Source and hashes: tools/art/generate_system_biomes.py and
art-library/voidreign-art-system-biomes/GENERATION-MANIFEST.json.

## Menus, HUD, and controls

The interface atlas contains six resource icons, 38 status icons, 12 main command buttons,
40 order icons and eight auxiliary sprite sheets (arrows, close, tab, pager, detail and
selection controls). These are drawn specifically for VOIDREIGN in
tools/art/build_original_art.py, and listed with exact dimensions and SHA-256 hashes
in game-data/VOIDREIGN-UI-ART-MANIFEST.json.

## Reproduction and verification

Run from the repository root:

    python tools/art/generate_component_facility_art.py
    python tools/art/generate_ship_art.py
    python tools/art/generate_system_biomes.py
    python tools/art/build_original_art.py
    python tools/art/verify_art_assets.py

The integrity audit checks every native component and facility Pic Num, image dimensions,
uniqueness, all 72 faction hull portraits and minis, all six leader portraits, all six
system layouts and all tactical tile files, and the expected UI atlas sizes.

## Faction leader concept-art source

The six leader concept portraits use the free AI Horde anonymous volunteer pool and
AlbedoBase XL (SDXL). They are AI-generated concept art, not commissioned illustrations
or a claim of exclusive species artwork. Source provenance is retained in the
faction-leader archive. System backgrounds, components, facilities, hulls, icons, menus
and controls are deterministic original procedural artwork.
