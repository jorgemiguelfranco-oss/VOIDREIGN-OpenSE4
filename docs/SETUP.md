# Installing and starting VOIDREIGN

VOIDREIGN is a standalone game. Its original factions, technology tree, components, facilities, names and rules are shipped as the game's own data set. **You do not need to own or install Space Empires IV.**

## Windows

Run the `VOIDREIGN-<version>-windows-x86_64-setup.exe` installer. It installs the game, its bundled `GameData` folder, and a Start Menu shortcut. Choose **Start VOIDREIGN** on the final installer page or open it from the Start Menu.

The portable Windows archive can be extracted to a folder you control and launched with `VOIDREIGN.exe`.

## Linux

Extract the `VOIDREIGN-<version>-linux-x86_64.tar.gz` archive and run `./VOIDREIGN`. The game uses the bundled `GameData` directory beside the executable.

A Vulkan 1.3 driver is preferred. The client also supports OpenGL 3.3 as a fallback. The `--renderer=opengl` option forces that renderer.

## Start a game

Use **Quick Start** to begin with a playable faction immediately, or open **Game Setup** to configure the galaxy and participating empires before starting. The generated ruleset currently includes twelve playable factions and three independent powers. Campaign mode is not part of VOIDREIGN.

In a running game:

- **Galaxy Map → Chokepoints** highlights explored systems whose loss would split the warp network. Unknown routes are not exposed by this overlay.
- **Fleet Transfer** creates fleets, renames and disbands them, moves ships into and out of fleets, and sets fleet formation and strategy. The Ships windows include retrofit selection.
- Build resource-storage facilities such as Mineral Warehouses, Organic Warehouses and Central Warehouses. Stockpiles are capped by storage capacity; income that cannot fit is lost rather than silently retained.
- Develop colonies, research technologies, design ships and bases, build at shipyards, and issue movement orders through the existing native engine.

## Data, saves and troubleshooting

The game data is generated by the source build from `tools/generate_voidreign_data.py` and bundled beside the executable. Do not remove `GameData` from the installation.

Saved games and settings are kept separately from the installation:

| Platform | Default folder |
|---|---|
| Windows | `%APPDATA%\VOIDREIGN` |
| Linux | `~/.local/share/VOIDREIGN` (or `$XDG_DATA_HOME/VOIDREIGN`) |
| macOS | `~/Library/Application Support/VOIDREIGN` |

A portable copy can keep its files in a `userdata` folder beside the executable. Start the game, open **Settings → Files**, and enable **Keep saves and settings in VOIDREIGN's folder**. The game offers to copy your existing settings and saves without deleting or overwriting the originals. The included `PORTABLE-README.txt` explains the option.

The current run's log is `voidreign.log` in the user-data folder; the previous run's log is `voidreign.previous.log`. Include the log when reporting a crash or a reproducible problem.

`--classic-dir=DIR` is an explicit compatibility override for loading a classic data set. It is not required for normal VOIDREIGN play. The previous OpenSE4 setup guide is preserved as `OPENSE4-SETUP.md` for engine-development reference only.
