# VOIDREIGN starting origins

A starting origin is the political, social or technological history that shaped an empire before the first turn. It is selected in **Empire Setup → Starting Origin** and remains attached to the empire throughout the save.

Each origin grants two characteristic advantages and one characteristic disadvantage. Characteristic values are percentage-point changes applied after racial-point validation, so an origin does not spend the player's racial-point budget. Starting reserves are added to the treasury subject to real warehouse capacity.

**No Origin** is also available. It gives no bonuses or penalties and provides a standard start.

Computer-controlled empires receive origins from the same catalog. Their choices are deterministic for a given game seed.
